# Clouvent SEO

Applies Clouvent's approved SEO standards. Does not define business/market facts — reads them from source documents below.

## Must read

- `CLAUDE.md` → SEO — canonical technical SEO rules, including Local/Australian SEO.
- `PROJECT_BRIEF.md` — Australian market strategy, lead-gen context, and the approved sitemap.

This skill must never override those documents. If they conflict, stop and report the conflict rather than choosing silently.

## Use for

Public page implementation and review: metadata, semantic structure, Open Graph, canonical handling, structured data, sitemap/robots.txt, internal linking, image SEO, search-intent alignment.

## Rules

- Support Australian search intent naturally — no keyword stuffing.
- No artificial location pages — only where genuinely justified.
- No fabricated structured-data claims (e.g. review/rating schema not backed by real content).
- No invented business locations, credentials, or claims anywhere in metadata or structured data.

## Boundary with `clouvent-performance-accessibility`

This skill owns image SEO metadata (alt text, filenames, structured data). Technical image optimization (formats, sizing, lazy-loading) belongs to `clouvent-performance-accessibility` — do not duplicate that guidance here.
